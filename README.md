# 轻记 · 身体记录

简体中文体重和腹围记录应用，适配手机与电脑。无需安装依赖，使用 Node.js 运行。

```sh
npm start
```

在浏览器打开 http://127.0.0.1:5173 。

支持按日期添加、编辑、删除记录（每天一条，重复日期会询问是否覆盖）、体重与腹围趋势、7 天 / 30 天 / 全部筛选、目标设置、历史分页、CSV 导出。

数据保存在当前浏览器的 localStorage 中，不会上传服务器；不同设备、浏览器或网址之间不共享。清除浏览器数据会删除记录，请定期导出 CSV。默认不填充示例数据。

`npm run check` 检查 JavaScript 语法。字体可联网加载，离线时自动使用系统字体。
